## 核心流程

- [ ] 可以登入。

- [ ] 可以搜尋歌手。
- [ ] 可以搜尋活動。
- [ ] 可以開啟活動詳情。
- [ ] 可以收藏。
- [ ] 可以取消收藏。
- [ ] 可以建立購票任務。
- [ ] `/tasks` 正常。
- [ ] 可以設定提醒。
- [ ] 可以建立購票紀錄。
- [ ] `/records` 正常。
- [ ] 重整後資料仍存在。
- [ ] 登出再登入資料仍存在。
- [ ] 看不到其他使用者資料。
- [ ] 一般使用者不能進 Admin。
- [ ] 手機操作正常。
- [ ] 沒有水平捲動。
- [ ] 沒有明顯卡死。
- [ ] 可以提交 Bug 回報。
